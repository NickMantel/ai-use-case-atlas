# Provenance

AI Use Case Atlas was written from Mantel requirements in October 2026:

- Mantel's workshop method (Today / Ideal world questions, "As a…, I need…, so that…" capture, "the gap is the use case").
- Mantel's desirability, feasibility and viability scoring lenses and worked example.
- Mantel's size and effort matrix (scope and complexity against build effort and data availability).
- Mantel's Lean Canvas template for data, analytics and AI use cases.
- Mantel's governance and sequencing cycle (ideation, sizing, prioritisation and scoring, governance and sequencing).
- The "Next-Gen" option from Mantel's adoption options: common taxonomy, catalogue-connected sizing, algorithmic DFV ranking, instant accelerators.

The general idea of an AI use case intake and scoring tool is common across the industry. A third-party source-available repository (tjromack/ai-usecase-intake-console, which prohibits reuse) was looked at for its README and licence only. None of its source code, prompts, templates, rubric wording, user interface or assets were read, copied or adapted. This code base was written independently of it.
